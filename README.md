# XSS Sanitizer

POC Cyber Lab where we create our own XSS sanitizer.

## Project structure

- `sanitizer/` contains the interactive sanitizer demo and sanitizer implementation.
- `dom-manipulation/` contains the DOM manipulation practice page.

## Running

Serve the repository root with a static file server, for example:

```sh
python3 -m http.server 8080
```

Then open [the sanitizer demo](http://localhost:8080/sanitizer/) or [the DOM manipulation practice](http://localhost:8080/dom-manipulation/).
